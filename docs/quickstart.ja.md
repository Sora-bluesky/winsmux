# クイックスタート: デスクトップアプリ

このガイドは v0.38.0 のデスクトップアプリで、プロジェクトを開き、ペインで作業して成果物を確認する手順です。旧版のオペレーター／ワーカー画面とは操作が異なります。リリースから入手したアプリの版を確認し、その版に付属するガイドを使ってください。

通常の利用では、デスクトップアプリを使います。CLI 中心、ヘッドレス、スクリプト運用で使う場合は、このページではなく [インストール](installation.ja.md#cli-パッケージでのインストール) の CLI 経路を参照してください。

## 1. 事前に用意するもの

- 対象リリースが対応するWindowsビルドとCPU
- PowerShell 7+
- デスクトップ画面に使うMicrosoft Edge WebView2 Runtime
- 使いたいエージェントの公式 CLI。AI起動画面で選択できるのはCodexとClaude Codeです。

`winsmux` が AI サービスへ代理ログインすることはありません。各エージェント CLI は、それぞれ自分のログイン状態や API キー設定を使います。

## 2. デスクトップアプリをインストールする

1. [リリース一覧](https://github.com/Sora-bluesky/winsmux/releases)で使用する版を選びます。
2. CPUに対応するWindowsセットアップを選び、その版の検証情報で確認します。
3. インストーラーを実行します。
4. インストールが終わったら、Windows の検索またはスタートメニューから `winsmux` を開きます。

Windows の検索結果やスタートメニューにバージョン番号が表示される必要はありません。通常の Windows アプリとして `winsmux` が表示され、開けることが重要です。

## 3. プロジェクトフォルダーを開く

デスクトップアプリが起動したら、エージェントに作業させたいプロジェクトフォルダーを選択します。

「プロジェクトを開く」でローカルのフォルダーを選びます。プロジェクト一覧で選択したフォルダーと、表示された作業場所を確認してください。CLI 用の初期化コマンドを手で実行する必要はありません。

「一覧から外す（ファイルは保持）」は登録を外す操作です。プロジェクトのファイルを削除する操作ではありません。

## 4. ペインで作業する

「新しいペイン」でターミナルを開きます。「左右に分割」「上下に分割」で作業領域を分けられます。操作する前に、選択したプロジェクトとペインを確認してください。

日本語入力はターミナルをクリックしてから行います。IMEで入力し、スペースで変換してEnterで確定してください。シェルでコマンドを実行するEnterと、IMEの確定操作を区別してください。

「操作検索」から操作を探せます。アプリのショートカットは Ctrl+Shift+P（操作検索）、Ctrl+Shift+T（新しいペイン）、Ctrl+Shift+W（選択したペインを閉じる）です。「アプリのショートカットを使う」を外すと、これらをアプリの操作に使わなくなります。

## 5. AIを選んで起動する

1. 対象のプロジェクトとペインを選び、CodexまたはClaude Codeを選択します。
2. 検出された公式CLIと作業場所を確認します。CLIを更新した場合は「導入状況を再確認」を使います。
3. 必要なら「モデルと推論の設定（任意）」を指定します。空欄では公式CLIの既定値を使います。
4. 「起動内容を確認」を押し、対象・作業場所・設定を確認してから「確認した内容で起動」を押します。
5. 「ターミナルへ戻る」で指示を入力します。ログインが必要な場合は公式CLIの案内に従ってください。

プロセスの「稼働中」と、AIの作業の「完了」は別の状態です。「未確認」と表示された場合は、完了や失敗と決めつけず、ターミナルの結果と表示された根拠・観測時刻を確認してください。中断には「現在の実行を中断」を使い、終了の観測まで確認します。

## 6. 成果物を確認する

「成果物」で「ファイルを選ぶ」、またはGitの候補から登録し、「成果物を再確認」で一覧を読み直します。登録したファイルを選択して「本文を読む」「差分を読む」を使ってください。バイナリは本文を表示しません。ファイルが消失した場合は、古い本文を現在の内容として扱わないでください。

AIの結果は、ファイルの内容・差分と実行結果を確認してから採用します。

## 7. 配置を復元する

「配置」の「配置だけを復元」で保存済みのペイン配置を戻します。配置の復元では、以前のシェルやAIを自動実行しません。対象を確認してから、必要な実行を明示的に開始してください。

## 8. ペインを閉じる

実行中のペインを閉じる際は、表示された対象と中断の確認を読みます。続ける場合は「戻る」、終了する場合は「中断して閉じる」を使います。結果が未確認のままなら、「状態を読み直す」で確認し、閉じたと決めつけないでください。

## 9. うまく開かない場合

次の状態は正常な起動ではありません。

- `localhost` への接続エラーが表示される
- 黒い PowerShell や Windows Terminal だけが表示される
- 画面が真っ白、または極端に小さいウィンドウだけが残る

この場合は [トラブルシューティング](TROUBLESHOOTING.ja.md) を参照してください。

## CLI で使いたい場合

CLI 中心、ヘッドレス、スクリプト運用では、使用する版のCLIパッケージとその手順を使ってください。v0.38.0ではGUI・CLI・MCPが共通のworkspaceを操作します。旧版の `winsmux init` / `winsmux launch` によるWindows Terminalの起動手順とは異なります。

手順は [インストール](installation.ja.md#cli-パッケージでのインストール) に分けています。デスクトップアプリの初回手順とは混ぜないでください。
